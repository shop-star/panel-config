# panel-config

Code for the custom timber panel builder/quoter widget embedded on the
City Timber Squarespace site (a drag-based SVG visualization with sliders
for width, length and thickness).

`panel-widget.html` is pasted as-is into a single Squarespace Code Block
(style, markup and script together, the way Squarespace embeds work).
Submits to Formspree (`https://formspree.io/f/xdabvwvj`).
